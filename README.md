# SML Abogados — Next.js

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- App Router + TypeScript. Estilos en `app/globals.css` con CSS anidado nativo.
- Contenido editable en `lib/content.ts`.
- Formulario: pensado para Netlify Forms (`public/__forms.html` registra el form). Para Netlify con Next.js, usar el runtime oficial de Next en Netlify.
